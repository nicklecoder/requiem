Keep every rejection in one append-only _rejected.md per namespace, on the grounds that a rejection is a lighter-weight companion to a statement and does not warrant its own file. Rejected: the shared file made an individual record unaddressable by discard, mv and update, and two agents rejecting different ideas in one namespace wrote to the same file. Lighter-weight than a statement is a claim about which fields a record carries, not about how many records share a file.
