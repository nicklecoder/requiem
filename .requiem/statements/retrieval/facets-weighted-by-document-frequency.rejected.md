Weight a shared facet by inverse document frequency so common identifiers stop dominating audit, mirroring the adaptive filter check already applies to lexical query terms. Rejected on measurement: in requiem own corpus the noise token must_not appears in 3 in-scope statements while genuine domain identifiers appear in 2, so rarity ranks the noise above the signal. Frequency is the right instrument for prose, where a saturating word is by definition uninformative, and the wrong one for identifiers, where a rare token is as likely to be schema vocabulary as a domain name.
